# Project Information

**Project:** Patient Health Monitoring Dashboard  
**Version:** 2.0 portfolio refactor  
**Developer:** Marcus Faulkner  
**Category:** Healthcare Information Systems / Front-End Analytics / Cybersecurity Awareness

## Objective

Demonstrate an end-to-end information workflow using synthetic healthcare-style data:

1. create a fictional patient record;
2. capture structured vital-sign observations;
3. validate inputs;
4. persist demo data in the browser;
5. calculate dashboard metrics;
6. visualize time-series information;
7. generate simplified rule-based flags;
8. document security and privacy limitations.

## Portfolio Boundary

This project is deliberately positioned as an **educational information-systems demonstration**, not a clinical product. It contains no real patient information and should not be used for healthcare delivery.
